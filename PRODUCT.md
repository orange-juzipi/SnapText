# Product

## Register

product

## Users

SnapText is for desktop users on macOS, Windows, and Linux who need to translate text from screenshots, selected desktop text, or local images without switching tools. Users are typically in a focused reading, research, development, or document-review workflow and need a compact utility that stays out of the way.

## Product Purpose

SnapText provides PP-OCRv6 based OCR and translation for three primary desktop flows: screenshot recognition to translation, selected-text translation, and image translation. Success means users can trigger capture or translation quickly, understand required permissions and model status, and copy, pin, retry, or review translation results without losing context.

## Brand Personality

Practical, calm, precise. The interface should feel like a reliable desktop tool: clear labels, predictable controls, compact panels, and direct feedback.

## Anti-references

Avoid marketing-style landing screens, decorative dashboards, oversized hero layouts, excessive animation, unclear helper windows, and English-only operational feedback in the default Chinese experience.

## Design Principles

- Keep the first screen usable immediately; no hidden content below an empty first viewport.
- Create auxiliary windows only when a user action requires them.
- Prefer familiar desktop utility controls over custom or decorative affordances.
- Make status, permission, model, and translation feedback readable in the active UI language.
- Keep advanced configuration visible but secondary to the core screenshot, selection, and image translation flows.

## Accessibility & Inclusion

Target clear contrast, keyboard-reachable controls, reduced surprise from automatic windows, and explicit permission guidance for macOS Screen Recording and Accessibility, Windows UI Automation, and Linux X11 or Wayland selection paths. Default interface language is Simplified Chinese with an English switch available in settings.
